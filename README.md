# DexCapTwist project website

Static project page for **DexCapTwist: Synthetic Asset Generation with Hybrid Primitive Control for Dexterous Screw-Cap Manipulation**.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

- `index.html` — single-page project site
- `assets/css/styles.css` — responsive layout and visual system
- `assets/js/main.js` — mobile navigation and scroll reveals
- `assets/images/` — web-optimized paper figures
- `assets/paper/` — compressed manuscript PDF
- `video/` — web-ready simulation and real-world experiment videos

The paper remains anonymized to match the current IEEE TASE manuscript.
